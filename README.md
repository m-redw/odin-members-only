# odin-members-only

## Premise

A fun little backend project I made for the Odin Project.

A simple chat room that only users can see.
Members who are registered can see who the author of a post is and when they posted it.
Admins can delete messages.

## Features:

- Sign-up form.
- Secret password checks to become a member or admin.
- Form validations.
- Message creation.
- Message logs/history.
